# Arabic Intelligent Knowledge Assistant

This project is the foundation for an Arabic Retrieval-Augmented Generation (RAG) system designed to answer questions from Arabic PDF documents with grounded citations and enterprise-friendly architecture.

## Current phase
Phase 1: project foundation and infrastructure.

This repository currently contains the clean architecture skeleton for:
- FastAPI backend
- Streamlit frontend
- PostgreSQL connection layer
- Qdrant connection layer
- centralized configuration and environment management

It intentionally does not include RAG logic yet.
